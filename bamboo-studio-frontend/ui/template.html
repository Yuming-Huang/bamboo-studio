01/ 06 当前步骤

Karamba3D · 本机联动

本软件通过本机 Rhino 8 中的连接插件调用 Karamba3D。请先启动 Grasshopper 和 BambooKarambaStart，再在第五步连接。计算需要有效的 Karamba3D 许可证；模型不上传远程服务器。

模型右上角可“隐藏信息”收起数据卡片。“截图模式”放大画布，支持旋转缩放；可关闭方案名称与色标，保存纯净 PNG。按 Esc 返回编辑界面。

模型可切换“轻盈示意 / 实际杆径 / 中心线”。轻盈示意将所有杆件直径统一按 45% 显示，保留相对粗细；计算截面与 Rhino 导出不变。截图在边缘保留“杆径缩小显示”标识。查看真实粗细请切换“实际杆径”。

  1. 场地边界：设置场地长度、场地宽度与空间限高；长度表示完整场地虚线框。
  2. 单榀模数：扣除独立的两侧预留后自动适配场地，显示同一场地框与余量。手动改跨度或总高会切为自定义，也可恢复自动适配。初始上部矢高为上部跨度的 40%，并受场地限高约束；这不是第五步的结构优化结果。
  3. 线性阵列：设置端部预留（每端），由场地长度扣除两端预留得到阵列可用长度，再确定并固定榀距。
  4. 檩条布置：拱架与檩条仍显示虚线。
  5. 结构选型与多参数搜索：各列表首值形成同模数基准；按高度、外径与类型候选参数展开组合搜索，超预算不会截断。先查看结果，再明确采用方案，进入单独复核与编辑，用同一色标比较修改前后的应力；修改前与当前方案均有独立选择按钮；已算出结果的方案即使未通过初筛，也可生成屋面，并保留原初筛结论。随时可切回选型时的推荐。
  6. 屋面生成：选择随拱外挑或切线双坡，仅控制外观，不改变第五步预设荷载。可导出已选方案 .3dm。

“满足设定阈值”是什么意思？位移不超过本次位移限值（Limit=0 时取跨度 W/250）；Fc/Ft/Fb 均为正值时检查正应力组合比 ≤1；开启屈曲时检查最小有效正屈曲因子 ≥1。第五步可查看实际限值与逐项计算值。强度全0或屈曲关闭时对应项目为“未评估”。W/250 是演示初筛值，非通用规范要求。覆盖面积容差只影响跨型比较。

材料和荷载初值仅供研究演示，不是通用规范值。采用 Karamba3D 一阶梁分析，按等效圆管截面建模。没有完整规范组合、真实节点和二阶缺陷验算。线性屈曲因子用于初步诊断；初筛规则不等于规范安全批准。
